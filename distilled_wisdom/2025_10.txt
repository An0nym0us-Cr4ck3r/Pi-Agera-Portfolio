## 岡山地下鉄：経済効果とデメリット - 圧縮版

**前提:** 岡山都市構造 - 放射状鉄道、点型都市、人口約70万人（都市圏110万人）。

**経済効果 (メリット):**

*   **直接効果:** 3000億円規模建設で、1.5-2倍の経済波及（4500-6000億円）、数千人雇用創出。
*   **再開発:** 駅周辺地価上昇、中心市街地再生、商業エリア再構築（名古屋地下鉄「栄」例）。
*   **交通効率:** 岡山駅-表町-大学町-清輝橋-岡山南直結で通勤・通学改善、バス渋滞緩和、観光客増加。
*   **環境/社会:** CO₂削減、大気汚染改善、バリアフリー化、災害時代替ルート。
*   **長期効果:** 都市ブランド向上、企業/大学誘致、人口流出抑制、地方中核都市地位確立。

**デメリット/リスク:**

*   **建設コスト:** 軟弱地盤で高コスト（3000-4000億円）、年間予算の半分規模。需要不足リスク（1日10万人以上必要）。
*   **運営コスト:** 年間数十億円の赤字見込み、市の財政負担増。
*   **競合:** 既存の路面電車（岡電）との需要競合、岡電経営圧迫。

**補足:**

*   岡山は「面」より「点」の都市構造。
*   地下鉄は都市の「核密度」を高める。
*   建設は短期的な景気刺激効果大。
*   長期的な人口維持には有効だが、コストと需要が課題。



## スタバ高カロリーカスタム - 圧縮版

**概要:** スタバで最も高カロリーなカスタムは、公開データのみでは断言不可。理論的アプローチと実例を提示。

**高カロリー要素:**

*   全乳/高脂肪ミルク
*   シロップ追加 (バニラ、キャラメル、モカ等)
*   ホイップクリーム追加
*   ドリズル (チョコ、キャラメル等)
*   トッピング (チョコチップ、ナッツ等)
*   エスプレッソショット追加
*   最大サイズ

**ベース候補:**

*   エスプレッソアフォガートフラペチーノ (380kcal例)
*   クリームベース (甘さと脂肪分最大化)

**参考例:**

*   Java Chip Frappuccino (520kcal)
*   White Chocolate Mocha Frappuccino (550kcal)
*   White Hot Chocolate (640kcal)
*   47地元フラペチーノ (牛丼一杯レベル)

**最強カスタム案:**

*   クリームベース
*   ホワイトモカ+モカ+キャラメルシロップ (フルポンプ)

*   トッピング (全種類)

*   最大サイズ

**予想カロリー:** 600-800kcal (追加次第で更に高カロリー)

* **Successful Kernel Replacement (Difficult):** Requires matching GKI version, KMI level, compatible `vendor_boot` drivers, and disabled AVB verification.  80-90% bootloop rate expected.
* **Safer Alternatives:**
    * **Magisk Modules:** Kernel parameter adjustments (`/proc/sys/`, `/sys/devices/system/cpu/`).
    * **Anykernel:** Ramdisk modification (rebuilding `init_boot`).
    * **Vendor Module Addition:** Custom modules for wakelock/GPU control (KMI compatible).
    * **Powerhint Tuning:** `/vendor/etc/powerhint.json` for DVFS/power control.
    * **Scheduler Adjustment:** HMP -> EAS (Snapdragon 7 Gen 2).
* **LineageOS Dependency:** Relies on Motorola's `vendor_boot/vendor` – GKI replacement alone will likely break functionality.

## Debugging Bootloops - Condensed

* **Pre-requisites:** Unlocked bootloader, full image backups (`boot.img`, `init_boot.img`, `vendor_boot.img`, `vbmeta.img`, `dtbo.img`), ADB/Fastboot setup.
* **Logging:**
    * `fastboot boot patched_boot.img` (for panic logs).
    * `adb logcat` (for init logs).
    * `dmesg` (via serial or `adb shell dmesg` for kernel panics).
* **Error Classification:**
    * `Kernel panic`: ABI mismatch, driver issues.
    * `fstab mount failed`: `init_boot` configuration error.
    * `dm-verity failed`: AVB/signature issue.
    * `unable to find device tree overlay`: `dtbo` mismatch.
    * `segfault / undefined symbol`: Module ABI mismatch.
    * `SELinux denial`: Policy mismatch.
* **Troubleshooting Steps (Prioritized):**
    1. `init_boot`/`boot`/`vendor_boot` integrity.
    2. `dtbo` verification.
    3. `vbmeta`/AVB disabling.
    4. Kernel patching/governor testing.
* **Tips:**
    * Use USB-Serial for early logs.
    * Magisk Canary for safe `init_boot` patching.
    * Check GKI ABI with `/lib/modules/modules.abi`.
    * Test `fstab` and `powerhint.json` in a virtualized ramdisk.
